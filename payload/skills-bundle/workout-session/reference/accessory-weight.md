# accessory-weight.md

이 문서는 보조 슬롯의 weight_kg가 null이고 부모 리프트 캘리브레이션이 있을 때, % 추론으로 시작 추정치를 제시할 때 읽는다.

---

## 보조운동 무게 % 추론 (owner-confirmed 2026-07-18)

연관 대형 컴파운드가 이미 캘리브레이션돼 있고 파생/보조 종목 슬롯의 weight_kg가 아직 null(미측정)일 때, 그 대형 무게를 기준으로 보조종목 시작 추정치를 %로 잡아 제시할 것 -- 사용자가 무게를 몰라 멈추지 않게. 워밍업 40-60% 규칙과 같은 계열의 시작-추정 휴리스틱.
cross-ref: 이 코칭 제시는 표시/제안 전용 -- 실제 program.yaml weight_kg 쓰기는 세트 로그(`set-add`)의 로그시점 rx contract 경유.

- 예: RDL ~ 데드리프트 1RM(또는 현재 워킹세트)의 55-65%. 그 외 파생쌍도 같은 원리로 보수적 하단부터.
- 성격 = 시작 추정치일 뿐. 반드시 "추정" 라벨을 붙여 안내하고, 첫 실제 세트의 RIR로 즉시 캘리브레이션한다. 처방/측정값처럼 단정해 말하지 말 것.
- program.yaml 기록: 이 추정치로 slot weight_kg를 채울 땐 measured처럼 쓰지 말 것 -- last.source='pct_infer'로 주석. 이미 캘리브레이션된 weight_kg(실측)는 이 추론이 override하지 않는다 (발명수치가 측정값 override 금지).

## M3 밴드체크

실제 보고 무게가 추정과 >15% 벌어지면 1줄 확인.

## 직접 파생쌍 없는 완전 신규 종목 (2026-08-01, C4/C11)

"제일 낮은 값/최소 핀"으로 후퇴 금지. 직접 파생쌍(예: RDL~데드리프트)이 없어도, 사용자 해당 근육군의 전반적 강도 수준(인접 대형 리프트 참조 -- 예: 하체 종목이면 v_squat/데드리프트 워킹세트)을 기준으로 보수적 추정치를 제시할 것. 위 % 추론 원칙의 스코프를 "직접 파생쌍 없음" 케이스까지 확장 -- 최소값 폴백이 아니라 전반적 근육군 강도 수준 -> 보수적 추정 흐름.

## 근거 표기 정확도 (2026-08-01, C4/C11)

추정치를 제시할 때 근거 강도를 있는 그대로 밝힐 것:
- (a) 실제 계산 근거(체중/골격근량/연관 리프트 % 기반)가 있으면 그 근거를 정확히 명시.
- (b) 진짜 감으로 잡은 추정이면 "감으로 잡은 추정"이라고 명확히 라벨링 -- 감 추정을 데이터 기반 계산처럼 포장하지 말고, 반대로 실제 계산 근거를 감처럼 축소하지도 말 것.

## 단일 관측치로 특성 단정 금지 (2026-08-01, C4/C11)

다른 첫세션 종목의 3세트째 결과 하나만 보고 "코어 지구력이 최상급은 아니다" 같은 특성/경향을 단정하지 말 것 -- 첫세션 단일 데이터포인트는 스킬/컨디션 노이즈일 수 있고 특성이 아님.

## 코드 산출 (live batch 2, 2026-10-08)

이력 없는 새 종목은 exercise-enter가 오늘 기록된 같은 동작군 리프트에서 추정치를 먼저 잡는다
(`WT_ESTIMATE_SAY:` 한 줄, 같은 장비 80% / 다른 장비 60%, 래티스 내림). "?" 행 대신 이 값이
세트표/램프/키보드에 실린다. 첫 세트가 목표 하한보다 2회 이상 모자라면 다음 세트가 그 세트
e1RM 기준으로 코드에서 내려간다(`LOAD_DECISION:`).
