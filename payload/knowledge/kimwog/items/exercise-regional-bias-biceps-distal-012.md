# exercise/regional-bias-biceps-distal-012

There is a plausible, but not yet statistically confirmed, case that preacher
curls grow the lower (distal) part of the biceps more than other curl
variants. The raw numbers moved in that direction in a 9-week study, but the
formal statistical test for "does the exercise choice actually change which
region grows more" did not reach significance -- so the pattern could be
noise. A larger, more recent study also disputes which curl variant is
actually the "long muscle length" one, which is the mechanism this claim
leans on.

Net effect: treat a preacher-curl-favors-distal-biceps program choice as a
reasonable, evidence-consistent guess, not a settled finding -- present it
with visible hedging and note the contested points rather than as confirmed
science.
