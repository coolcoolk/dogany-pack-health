# exercise/effective-sets-fractional-008

When counting weekly sets per muscle, a set where the muscle is the prime
mover should count as a full set, and a set where it is a secondary helper
(synergist) should count as a half set -- this fractional scheme beats simply
adding up every set a muscle touches, and the distinction between the two
kinds of sets matters enough that it should not be collapsed.

The caveat: the underlying study validated this 0.5 weighting in aggregate,
across its pooled dataset -- it did not separately verify every specific
exercise-to-muscle synergist assignment. Applying the same flat 0.5 to every
synergist slot in a program engine is a sound extrapolation of the finding,
not an independently confirmed number for each mapping.
