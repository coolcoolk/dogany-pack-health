# cooking/contested-toxicity-default-004

Two food-safety scares get different treatment here. Double-blind testing has
failed to reproduce "Chinese Restaurant Syndrome" from MSG -- harm only
appears at gross overdose levels -- so the popular scare is downgraded and
normal dietary MSG use grades as safe.

PTFE/PFOA (nonstick cookware chemicals), by contrast, has a thin and
inconclusive toxicity evidence base. The rule applied here is default-
conservative: a thin evidence base gets flagged as contested/insufficient
rather than being asserted as either safe or unsafe. Note the underlying PTFE
source is low-tier and the PFOA epidemiology is time-scoped, so this should be
revisited if better evidence surfaces.
